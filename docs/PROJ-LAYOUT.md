# Project Layout

`noizu_labs_core` (GitHub: `noizu-labs-scaffolding/core`) — core Noizu Elixir
scaffolding: an entity-reference identity protocol, a request-context record,
and shared helpers. Small pure library: 26 tracked files, ~1k lines of Elixir
across 12 modules; no persistence, no runtime dependencies.

## Notes

- **No setup-requiring files.** The library has no runtime dependencies and
  reads no environment variables; a checkout only needs `mix deps.get`
  (dev-only tools: credo, ex_doc).
- `.meta/pointers.yaml` is generated by
  [doc-pointers](https://github.com/the-robot-lives/doc-pointers); verify with
  `doc-pointers build --root . --check`, never edit by hand.
- `README.md` is leftover scaffolding text (wrong app name `NoizuErp`,
  package `noizu_labs_erp`); `CLAUDE.md` carries the accurate identity
  (core Noizu scaffolding, v0.1.8, Hex-published).
